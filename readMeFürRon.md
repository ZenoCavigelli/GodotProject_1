1. Commits.
	Wenn du etwas änderst und die Änderungen speicherst, musst du den Root-Folder
	(Den Ordner über dem Projekt) in einem Terminal öffnen.
	Gib anschliessend die folgenden Befehle ein.
	
	Ps die Blauen Komentare gehören nichtr zum Befehl.
	git status   #Du siehst ob es uncommitete änderungen gibt.
	git add .   #Du fügst die Änderungen an den comit an.
	git commit -m "DEINE_COMMIT_MESSAGE"   # Du committest und fügst in die ""
										   # Eine kurze Nachricht ein was du geändert hast.
	git push   # Pusht die Änderungen in das GitHub-Reposetory. Änderungen Erst dann dort verfügbar.
	
2. Assets
	Assets sind Dinge für das Frontend. Töne Sprites(Visuelle Grafiken) usw.
	
3. Scenes
	Scenes sind sozusagen Besandteile, aus denen das Projekt zusammengesetzt wird. Zb Knight (Der Spielercharakter)
	und game (Das Level)
	
4. Scripts
	Scripts sind Codefiles, die logische Operationen und Rechnungen im Hintergrund erledigen.
